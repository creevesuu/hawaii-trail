# Voyage to Hawaiʻi

A family-friendly, choice-driven browser adventure inspired by traditional Polynesian voyaging and wayfinding. Guide a fictional crew toward Hawaiʻi while managing food, water, morale, and canoe condition.

## Play
**[Play Voyage to Hawaiʻi online](https://hawaii-trail.silvermoth9.chatgpt.site)** — no download needed. The hosted game currently requires the owner's ChatGPT sign-in.

The hosted edition includes the illustrated journey and resource/layout fixes from `codex/choice-learning-loop` at commit `c58438277e271b70862be41f4a6f1b965fba0f50`. It is published through ChatGPT Sites; future updates can use the same address. GitHub pushes alone do not automatically deploy this Site.

For offline play, open `index.html` in a modern browser.

## Controls
Click or tap a choice each turn. Survive the voyage and reach land.

## About
This is an early playable prototype, not a historically complete portrayal of the first settlement of Hawaiʻi. Future versions should include careful research, consultation with Native Hawaiian cultural experts, illustrated scenes, and more nuanced navigation systems.
